01 — The Problem
ARC Global had zero products. Zero benchmark data. Zero prior R&D.

As the sole mechanical engineer intern — joining ARC Global during the summer break after 4th semester — the brief wasn't to optimize a vehicle. It was to prove one could exist at all. No legacy platform to adapt. No in-house data to anchor decisions.

Priority: close the loop from concept to a real, manufacturable CAD prototype. Refinement — weight, cost, performance — was deliberately deferred. It can only happen once something exists to refine.

02 — What I Worked On

Key Milestones.

Six phases, one month. Each phase fed directly into the next.

01Reverse Engineering a Reference Product

No physical vehicle. No spec sheet. Working entirely from images of a reference dune buggy sourced online, I systematically extracted all key dimensions — wheelbase, track width, seat position, roll cage proportions — using image scaling and reference-object estimation. This became the benchmark dataset for every downstream design decision.

05 — Reflections

What I Learned.

One month. Full ownership. Two key lessons.

01
Reverse engineering from images is a real methodology

With no physical access to the reference vehicle, all benchmark dimensions were extracted from online images — using scale estimation and reference objects. It forced precision in observation and made every downstream number defensible.

02
Parallel workstreams are the only way to hit tight deadlines

CATIA, Lotus Shark, and SolidWorks ran simultaneously — not sequentially. Keeping partial models consistent across tools while each was still evolving was the hardest skill.
